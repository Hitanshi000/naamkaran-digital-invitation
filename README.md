# Naamkaran Digital Invitation 🎉

A personalized digital invitation website created for my nephew's Naamkaran (naming ceremony). The project brings together traditional Indian cultural elements and an interactive digital experience.

🌐 **Live Website:** https://naamkaranceremony.netlify.app/

## ✨ Features

- **Interactive Welcome Screen:** A themed opening experience featuring Lord Ganesha.
- **Traditional Invitation Cover:** Shiv Parivar-inspired design with a Naamkaran ceremony theme.
- **Animated Opening Experience:** An animated seal that creates an interactive transition to the invitation.
- **Invitation Display:** Displays the actual ceremony invitation image.
- **Audio Integration:** Background devotional music, flute audio and bell sound effects.
- **Quick Navigation:** Dedicated buttons for accessing venue and contact information.
- **Themed UI:** A combination of soft blue, ivory and gold tones inspired by traditional Indian celebrations.

## 🛠️ Tech Stack

- **HTML5** – Website structure and content.
- **CSS3** – Styling, layouts, animations and visual design.
- **JavaScript** – Interactive elements, screen transitions and audio controls.
- **Netlify** – Website deployment and hosting.

## 🚀 Run Locally

To run this project on your local machine:

1. Clone the repository:

   ```bash
   git clone https://github.com/Hitanshi000/naamkaran-digital-invitation.git
   ```

2. Navigate to the project directory:

   ```bash
   cd naamkaran-digital-invitation
   ```

3. Open `index.html` in your web browser.

No additional dependencies or installations are required.
